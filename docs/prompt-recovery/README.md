## 文件对应关系

- `site/pendulum-rhythm/` 是恢复的参考前端，原署名与说明保留。
- `site/prompts/pendulum-rhythm/v1.md` 是该次生成的完整输入。
- `site/generated/pendulum-rhythm/blind-01/` 是新上下文从空目录做出的结果。
- `site/prompt-lab/` 提供提示词与演示的公开展示入口。
- `docs/prompt-recovery/pendulum-rhythm/` 保存分析依据、生成前验收、输入哈希、封存、独立检查与评价。

v2光效改进版保留v1物理与交互，增加灯光及反射；已依据参考反馈修改，尚未进行新的从零盲测。

初次盲测生成方只收到已锁定的提示词与通用环境说明，可以看自己的页面、自检并修复。完成后停止修改，父代理封存结果，再观看参考版做对照。没有向生成方传递原代码、画面或参考反馈。共享文件系统下的指令约束不等同于操作系统强隔离；单次上下文及其自检轮次不能计算生成成功率。

## 怎么复用

1. 查看或复制对应版本的完整提示词，在新的 AI 编程会话中使用。
2. 让它从空目录交付可运行网页和源码，记录实际模型配置与自检修复。
3. 按 [生成前标准](pendulum-rhythm/CRITERIA.md) 检查物理、回放与交互，再比较实际动态画面。
4. 若修改提示词，建立新版本及新生成轮次，不能继续沿用旧演示的验证结论。

原理仿真可做成纯前端，但数据类场景可能需要公开接口、素材或快照；各项会明确区分实时与演示数据。GitHub 仓库保存源码，在线托管需另行配置；当前给出本地运行入口。
