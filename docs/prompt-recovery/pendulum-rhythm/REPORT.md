- 地面只有环境反射，没有实际仪器的平面倒影；阴影为PCF近似，玻璃没有真实折射。
- 展厅与高光比较简单，应在下一版本明确给出反射、曝光及金属配色的可验收画面要求。
- 枢轴轮毂与主体画面比例偏小，标题和控制面板偏大；需更严格定义镜头取景与界面占比。
