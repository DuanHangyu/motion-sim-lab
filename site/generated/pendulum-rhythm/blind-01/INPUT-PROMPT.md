# 摆的节律：独立生成主提示词 v1

从零制作一个可以直接在浏览器运行的高质量 3D 交互实验室，主题是“两根长度不同的摆，从同一角度同时释放，逐渐错相，再重新同相；还能切换十五摆的摆波”。本任务只提供文字描述，不提供现成项目、参考图或场景代码。请交付完整源码、运行说明和实际验证记录，不要只做效果图或播放预录视频。

## 1. 画面与造型

整体是一台精密桌面实验仪器，位于暮色展厅里。正面略俯视的主镜头下，中间是钢制门形摆架，前面是宽大的枪灰色楔形控制台，背后是蓝灰色墙、窄窗、侧边小展示板和几棵放在小白盆里的低多边形松树。底部是暗亮的地面，有柔和反射。注意主角是可触摸的机械仪器，不能退化成两条线、两个普通球和一个空背景。

采用统一场景单位：1 个场景单位 = 10 cm。y 竖直向上，z 正方向为仪器正面。

- 控制台约宽 13.7、深 4、高 2；上面平整，前控制面从顶部向前下方倾斜，两个侧盖比中间面略厚。控制台前底部有两道连续、柔和的暖金色灯带；四角有倒角和接缝。底部接近地面，但避免穿透。
- 钢制门架立在控制台上：左右立柱中心 x=±3.35，后移 z≈−0.43；柱脚由底座、四颗黄铜螺栓、短宽方块、细长方柱组成。横梁顶端 y≈7.22，厚≈0.49、深≈0.5。横梁两端有黄铜连接块与银色螺栓。金属边缘要有窄高光，不是大块全黑物体。
- 两个真正的转轴位于 x=−1.45 和 +1.45、y≈6.70、z≈0；横梁下的轴承夹具、垫片、横销、轮毂和圆形枢轴盘应能看清。左轮毂银钢色，右轮毂偏黄铜。杆绕固定枢轴旋转，不能让枢轴跟着球移动。
- 默认左摆中心距 36.9 cm（场景长度 3.69），右摆 23.1 cm（2.31）。左球半径 3.4 cm（0.34），右球 2.5 cm（0.25）；两颗摆球都是金黄铜的有棱面球体，约 80 个三角面，带上方小夹头、细颈、下方短锥形尖端。左杆银钢色、右杆黄铜色。杆粗约 0.04。金属杆延伸到球夹头，不能露出贯穿球体的尾巴。
- 默认两摆均从向左偏转 16°、角速度为零的状态释放。长摆的球明显更低，且更大。摆只在各自的竖直平面内运动，保持杆长不变。
- 门架内部背后可有透明淡蓝灰玻璃板，低不透明度，蓝色细边；玻璃不能挡住球、相位环或曲线。
- 门架中央 y≈4.7 放一个半径≈0.8 的悬浮相位环：四层细同心圆，蓝色和琥珀色指针/点在不同半径上绕圈。相位来自两个摆的真实运动。相位接近时出现轻微白金色闪光与“in step”提示。
- 在门架下部 y≈3.05 叠加两条细发光的角度—时间曲线，蓝色与琥珀色。中央竖线是当前时刻，左侧为过去，右侧为同一模拟的未来预测。不是装饰性固定正弦波。
- 摆球后有短暂轨迹与最多三颗半透明灰蓝“过去位置”残影，亮度渐淡，来自回放采样；不要误做多个实体摆球，残影不能遮挡黄铜主球。枢轴附近带细角度刻度。
- 控制台斜面左右各有一个真实 3D 圆形长度旋钮，左蓝右琥珀，有刻度、发光弧、数值与指针；中间是嵌入的长条玻璃时间带，绘制两条角度曲线、同相/反相标记和施力事件。时间带中心播放头固定，带面相对时间滚动；两侧有跳转箭头。

主镜头 FOV≈30°，目标 (−0.3,3.02,0.1)，距离≈17.32，正面 yaw=0、轻微俯视 pitch≈0.172。根据窗口比例与界面遮挡自动适配：1440×1020 中整个门架、球、控制台前旋钮都在画面里，主装置占画面宽度约 70–90%，主体不被裁掉。移动端应重新拟合镜头、预留顶部指标和底部操作区，不能只缩小桌面界面。

## 2. 材质与灯光

场景是蓝灰暮色与暖金色仪器灯的平衡：背景 #0f1620 到 #263348，钢色 #5a626f，控制台 #2f353f，黄铜 #e2b66c 与 #b0843f，蓝 #72b8ff，琥珀 #ffb454，界面强调青 #7fe3ff。

金属应使用 PBR：钢 metalness 约 0.6–1、roughness 0.16–0.35；黄铜 metalness 0.75–1、roughness 0.2–0.34，轻 clearcoat。环境反射由程序化展厅/灯板经 PMREM 生成，或等效可离线实现的环境；没有环境反射，金属容易发黑。暖主光从右上前方照入，冷柔补光与背缘光区分轮廓。阴影柔和，有接触阴影；台面与地面可用合理性能的反射方案。灯带、蓝金轨迹只做局部柔和泛光，不让画面过曝成橙色一团。薄玻璃仍可看透。

用 Three.js 0.183.2 / WebGL2 或等效浏览器渲染方式。所有几何、纹理和环境都可程序生成；不要从目标作品下载模型、贴图、源码或视频。采用完整合规的通用库可用的标准后处理，不得声称仅靠透明度便实现了真实折射。不能以灰白平面图替代 3D。

## 3. 运动模型与时间一致性

实现完整非线性摆：θ″ = −(g/ℓ_eff)sinθ − cθ′，g=9.81 m/s²，c≈0.004 s⁻¹。物理尺寸以米计算，绘图才换算成场景单位。对于球心距离 L、球半径 r，球体转动惯量的等效长度 ℓ_eff=L+0.4r²/L。支架刚性，轻杆、轻轮毂不计质量；不做支架耦合或碰撞。

采用 RK4 或同等精度的固定时间步积分，dt≤1/480 s。缓存每秒至少 120 个样本的角度、角速度和连续展开相位，渲染时插值。物理不依赖屏幕刷新率；暂停冻结物理时间，0.25×/0.5×/1×只改变模拟时钟。相位、球位姿、轨迹、历史/未来曲线、事件、读数必须来自同一个模型时刻。

周期可用有限幅度修正：T=2π√(ℓ_eff/g)/AGM(1,cos(A/2))，其中 A 是振幅。默认周期约 1.227 s 和 0.971 s；初始拍频相遇间隔约 4.66 s。大幅度周期略长，不得直接用不同 CSS 动画周期伪造。

连续相位可由 atan2(ω/Ω,−θ) 估计，并解绕避免 2π 跳变；Ω 用当前能量估算的非线性周期。扫描同一缓存，求相位差跨过 2π 整数的同相时刻、跨过奇数 π 的反相时刻。界面中的 1/|1/T1−1/T2| 是解释用估计；跳转和时间带的事件必须取模拟检测结果。近相等长度时拍频时间很长，相等时显示持续同相或无有限拍频，避免 Infinity/NaN。

时间轴至少支持 0–24 s；需要时延长到 180 s，并支持确定性回放与任意往返拖动。给一个摆施加瞬时角速度增量时，按模型时间记录事件。回到施力之前，状态回到之前；再次向前重播该施力。若在过去新施力，丢弃其后的旧分支事件并重算未来。施力应有振幅上限，避免杆、球撞台面。改变摆长或释放角时，把两个摆抓回一致的释放角，再重新同时释放，清空旧施力。

## 4. 预设与十五摆

提供五个预设：

- Drift：L1=.369 m、L2=.231 m，释放16°。
- 5:4：L1=.369 m，通过数值反解 L2，使包含球半径修正后的 T1/T2=5/4；不是把长度直接设成5/4。
- 3:2：L1=.36 m，反解使 T1/T2=3/2。
- Twins：L1=.30 m、L2=.28 m，展示相近长度会延长相遇间隔。
- Wave：改为十五根轻细钢杆、小黄铜棱面摆球，等间距 x∈[−2.66,2.66] 排在横梁下，摆动方向为 z 方向；球半径 .013 m、释放角13°。数值反解每根长度，使其初始非线性周期为 60/(51+i) s（i=0…14），使用相同的非线性模拟。中途出现行进波、二组/三组/四组队形；约60 s再次整齐。微弱阻尼会改变有限幅周期，因此不要声称存在数学上永久精确的60 s复现。判断队形可用平均 exp(i*m*phase) 的模，m=1…4；不要只按固定时刻换动画。

Wave 模式镜头略绕到侧前方，以看清十五摆的深度方向运动。两摆模式的隐藏对象不可残留。返回 Drift 恢复两个摆和对应控制。十五摆与双摆都能暂停、拖时间、切换视图。

## 5. 页面和直接交互

界面不需后端，不需账号。左上是小白标题 PENDULUM RHYTHM LAB，大青色标题 FIND THE RHYTHM，简短英文解释；下面三块紧凑深色指标为 Blue swing、Amber swing、In step every，再下面解释当前是否锁定简单比例。右上约356px宽深蓝半透明圆角控制卡，依次安排：五个预设、两根长度滑条和数值、播放/暂停与时间拖条、上/下个同相时刻、Blue/Amber push、1×/½×/¼×、Release、Lab/Exploded/Studio、Cinematic和How it works。字体可用系统无衬线和等宽数字，所有依赖离线可用。

滑条范围：蓝20–37 cm，琥珀9–30 cm。提供键盘可访问的真实滑条/语义；控件不与相机拖动互相抢事件。旋钮或滑条可吸附简单周期比，至少1:1、5:4、4:3、3:2，锁定时视觉提示。

实现3D拾取：拖球沿杆方向改变长度；横向拖球改变两者释放角，松手同时释放；点击/轻拂球给该摆施力；台面旋钮可拖动改变长度，点击跳到可达的下一简单比例；拖动台面时间带拖时间，点击标记跳转。背景拖动旋转镜头，右拖平移、滚轮缩放，移动端支持触摸操作。可用 Raycaster 与有足够命中尺寸的透明拾取代理，但不能只有装饰旋钮和装饰时间带。

三种视图：Lab 是上述暮色仪器；Exploded 用深蓝背景，将夹具、轴承、垫片、横销、轮毂、杆、摆球沿清晰方向分离并标注，模型时间与控制仍有效；Studio 用暖米白背景与柔和摄影光，突出金属、弧形运动轨迹和物体本身。视图切换不能重置模拟时间。

键盘：Space播放/暂停，逗号/句号步进，[/]跳同相，1–5预设，Shift+O/P推左/右摆，0同时释放，Shift+V轮换视图，R镜头复位，C切换缓慢电影镜头，/显示/隐藏界面。Help解释公式、有限球半径、非线性振幅、单独施力、缓存回放，以及忽略的物理因素。界面若改中文也保持同样信息。

手机390×844顶部放紧凑标题与三项指标，底部放可用控制；必要时折叠次要设置但两个长度必须可调整。画面不能横向溢出，主装置和球始终有可见空间。

## 6. 工程交付与自检

交付静态页面与可编辑模块，不需要业务后端，Node只用于提供文件。通用 Three 依赖请保存到候选目录的vendor中并保留MIT许可；至少保留实际用到的build和addons，页面相对路径可部署到网站子目录。依赖锁定版本，README写出启动和测试方法。

实现只读状态快照与明确测试接口 window.pendulumLab，至少含 ready、snapshot()、setPreset(name)、setTime(seconds)、play()、pause()、setSpeed(v)、setLength(index,cm)、push(index,deltaOmega)、release()、setView(name)、resetCamera()、setCinematic(bool)。快照返回time、playing、speed、mode、lengths米、angles弧度、angularVelocities、periods、phases、syncEvents、pushEvents、view、camera、渲染计数，并能取得当前可交互物体的屏幕坐标用于真实拾取测试。时间设定后模型和画面当帧刷新。

必须实际验证：默认周期与拍频、大小振幅周期差、5:4及3:2、暂停冻结、不同渲染步长同一物理时间一致、施力回放与重写未来、十五摆约60s重聚、参数极端有限值、视图切换不丢状态、至少一次真实球/旋钮/时间带拾取、桌面/手机无溢出、资源与控制台无错误。提供实际正常1×连续运行视频或可重复录制方法、默认/摆波/拆解/Studio截图与测试结果。性能只报告本机实测，不宣称普遍60fps。
